## 📖 Overview

**The Dragon's Quest** is a text-based role-playing game (RPG) developed using **JavaScript** and **Node.js**. Players begin their journey in a small village and progress by exploring new locations, purchasing equipment, battling enemies, and ultimately challenging a powerful dragon.

The project demonstrates fundamental programming concepts such as object-oriented data structures, game state management, inventory systems, user input handling, combat mechanics, and error handling in a terminal-based application.

---

## ✨ Features

- Interactive command-line gameplay
- Turn-based combat system
- Inventory management
- Weapons and armour upgrades
- Health potion system
- Gold-based economy
- Multiple explorable locations
- Boss battle with progression requirements
- Input validation and error handling
- Player statistics and status tracking

## 🎯 Gameplay

Your objective is to prepare your character for the final boss battle.

Typical progression:

1. Start in the Village.
2. Explore the Forest to earn gold.
3. Purchase stronger equipment from the Blacksmith.
4. Buy health potions from the Market.
5. Travel to the Mountain.
6. Defeat the Dragon and complete the adventure.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/yourusername/DragonQuest.git
```

### Navigate to the project

```bash
cd DragonQuest
```

### Install dependencies

```bash
npm install
```

### Run the game

```bash
node adventureGame.js
```

---

## 🎮 Controls

Navigate through the game using the numbered menu options displayed in the terminal.

During combat:

- Press **Enter** to continue attacking.
- Type **flee** to escape from battle.

---

## 🏆 Victory Conditions

To complete the game successfully, the player must:

- Defeat monsters to earn gold.
- Purchase the **Steel Sword**.
- Equip at least one shield.
- Maintain sufficient health.
- Defeat the Dragon Boss.
